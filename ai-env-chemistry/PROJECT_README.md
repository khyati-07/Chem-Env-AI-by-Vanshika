## 🚀 How to Run the Application

### Prerequisites
- **Python 3.x** (Download from [python.org](https://www.python.org/downloads/))
- That's it! No other installation needed. The app uses Python's built-in `tkinter` library.

### Steps

1. **Open Command Prompt / Terminal**
2. **Navigate to the project folder:**
   ```
   cd c:\temp\ai-env-chemistry
   ```
3. **Run the app:**
   ```
   python pollution_predictor_app.py
   ```

## 🖥️ Application Features

### Tab 1: AQI Calculator
- Enter pollutant concentrations (PM2.5, NO₂, SO₂, CO, O₃)
- Calculates Air Quality Index using Indian CPCB standards
- Shows health advisory and remediation strategies

### Tab 2: AI Prediction
- Input weather conditions (temperature, humidity, wind speed)
- Select season and city type
- AI predicts pollution level and explains its reasoning

### Tab 3: Indian Cities Comparison
- Displays approximate pollution data for 8 major Indian cities
- Shows AQI and category for each city
- Key observations about India's pollution patterns

### Tab 4: Learn
- Educational information about each pollutant
- Chemical reactions, sources, health effects
- India-specific facts
